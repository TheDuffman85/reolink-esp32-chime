Install Reolink ESP32 Chime

For ESP32-WROOM-32 development boards with 4 MB flash. ESP32-C3, S2 and S3 boards are not supported by this firmware.

Installation clears saved settings and pairing.

Use this installer for first setup or USB recovery. To keep your settings during a normal update, upload firmware.bin in the chime’s Settings → Firmware page.

Before you connect

  1. Open this page in desktop Chrome or Edge.
  2. Connect the ESP32 with a USB data cable. Close any serial monitor or other application using its port.
  3. Click Connect to ESP32 and choose the board’s serial port.
Can’t connect to the board?

If the port is missing, try another data cable or USB port and install the driver for your board’s USB serial adapter (often CP210x or CH340). On Linux, check your serial-port permissions.

If connection stalls, hold BOOT while connecting. If needed, press and release EN/RESET while holding BOOT. Release BOOT when writing starts.

Use the manual USB instructions above if your browser does not support Web Serial.

After installation

  1. Join the ESP32’s Reolink-Chime-xxxxxx WiFi hotspot.
  2. Open http://192.168.4.1/, then use Setup to connect to your 2.4 GHz WiFi.
  3. Connect the CC1101 radio according to the wiring guide, then follow the doorbell pairing instructions.

WiFi setup takes place on the chime’s own web page after flashing.
